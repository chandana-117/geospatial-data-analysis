# Geospatial Data Analysis

## Overview

This project analyzes regional sales and user data to visualize geographic distribution and identify potentially underserved regions.

## Objective

The objective is to visualize revenue and user distribution geographically and identify regions that may have potential for further market investigation.

## Dataset

The dataset contains:

- State
- City
- Postal Code
- Revenue
- Users
- Latitude
- Longitude

The dataset was created for this internship task because no sample database was provided.

## Analysis Performed

- Cleaned and organized regional data
- Compared revenue and user counts across cities
- Calculated revenue per user
- Created an interactive geographic map using Python and Folium
- Identified potentially underserved regions

## Potentially Underserved Regions

Based on the sample analysis:

1. Warangal
2. Karimnagar
3. Khammam

These regions showed moderate user demand with comparatively lower revenue in the sample dataset.

## Tools Used

- Microsoft Excel
- Python
- Folium
- HTML
- GitHub

## Project Files

- `Geospatial_Data_Analysis.xlsx` – Regional data and analysis
- `Geospatial_Data_Analysis_Report.pdf` – Spatial analysis report
- `geospatial_map.py` – Python code used to create the map
- `geospatial_map.html` – Interactive geographic map

## Conclusion

The geospatial analysis provides a visual understanding of regional revenue and user distribution. Warangal, Karimnagar and Khammam were identified as potentially underserved regions based on the sample metrics and can be considered for further investigation.
